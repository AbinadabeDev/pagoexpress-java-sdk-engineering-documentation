# Public Evidence

This folder is reserved for evidence that can be published safely.

The repository does not require proprietary source code to prove that the project was real.

Suitable evidence includes:

- a sanitized delivery timeline;
- independently recreated architecture diagrams;
- sanitized test summaries;
- public client references;
- redacted screenshots that contain no confidential material.

Do not add evidence merely to make the repository look more complete.

Every item must pass [`publication-checklist.md`](publication-checklist.md).
