# Delivery Summary

## Artifact

PagoExpress Java SDK.

## Delivery classification

Commercial client software.

## Publicly documented engineering scope

- Java SDK implementation;
- REST/JSON API integration;
- authentication;
- token lifecycle;
- typed request/response models;
- PIX;
- boleto;
- original card-related operations;
- transaction queries;
- capture;
- cancellation;
- reversal-related operations;
- webhook/asynchronous integration concerns;
- idempotency considerations;
- safe logging;
- sandbox validation;
- Maven packaging.

## Important separation

The Magento, WooCommerce, PrestaShop and Shopify implementations are separate projects and should receive their own documentation repositories or portfolio sections.

The later Card V2 evolution is also separated from the original SDK scope.
