# Pre-Publication Checklist

Run this checklist before publishing any new file, screenshot, diagram, log, example, or metric.

- [ ] The content was independently written for the public repository.
- [ ] It contains no client source code.
- [ ] It contains no renamed or lightly modified copy of client source code.
- [ ] It contains no private repository URL.
- [ ] It contains no credential.
- [ ] It contains no API key.
- [ ] It contains no access token.
- [ ] It contains no authorization header.
- [ ] It contains no production URL.
- [ ] It contains no internal IP address.
- [ ] It contains no customer personal data.
- [ ] It contains no real transaction identifier.
- [ ] It contains no database content.
- [ ] It contains no private endpoint path unless officially public and approved.
- [ ] It contains no private Swagger/OpenAPI contract.
- [ ] It contains no proprietary request/response schema.
- [ ] It contains no confidential screenshot.
- [ ] It contains no internal client conversation.
- [ ] It contains no contract or commercial value.
- [ ] Any metric is verifiable and safe to disclose.
- [ ] Any code example is fully synthetic.
- [ ] Any diagram is conceptual and independently recreated.
- [ ] The content does not mix SDK architecture with later plugin/backend architecture.
- [ ] Card V2 is not presented as part of the original SDK unless separately documented with verified evidence.
- [ ] The content is necessary to demonstrate engineering value.
